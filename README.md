# 📖 Starry Book Portfolio — Kaka Andrea Yahya

> 🌙 **Interactive 3D pop-up storybook portfolio** with Van Gogh-inspired visuals, scroll-driven page flips, and fairytale dioramas. Built with React, Framer Motion & Tailwind CSS.

---

## ✨ Features

- 📖 **Interactive 3D Pop-up Storybook**: Scroll-driven realistic book opening, page-flipping transitions, and 3D perspective depth.
- 🎨 **Van Gogh "Starry Night" Canvas**: Atmospheric living night sky with animated swirling brushstrokes, glowing stars, and crescent moon.
- 🎭 **Fairytale Dioramas**: Rich pop-up illustrations featuring treehouses, glowing lanterns, owls, and fireflies.
- 🌐 **Bilingual (ID / EN)**: Dynamic language switching without page reloads.
- 🎵 **Magical Audio Experience**: Ambient music box melody and parchment page-turn sound effects (with mute toggle).
- 📱 **Hybrid Responsive Modes**:
  - **Book Mode** (Desktop & Tablet Landscape): Full 3D interactive book.
  - **Page Mode** (Mobile & Small Screens): Fluid, readable story scroll.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Audio**: [Howler.js](https://howlerjs.com/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Kalzz76/starry-book-portfolio.git

# Navigate into the directory
cd starry-book-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```

The output will be generated in the `dist/` directory, ready to deploy to Cloudflare Pages, Vercel, or GitHub Pages.
